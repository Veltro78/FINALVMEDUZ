Mode Rave — easter egg caché (appui long ~1,5s sur le logo, accueil)

Pour utiliser votre vrai extrait à la place du kick synthétisé par défaut :

1. Prépare un fichier MP3 de l'extrait que tu veux utiliser
   (idéalement 10 secondes, format court, léger).
2. Nomme-le exactement : anthem.mp3
3. Dépose-le dans ce dossier (public/sounds/anthem.mp3).
4. Redéploie normalement (Working Copy → Commit → Push).

L'appli le détecte automatiquement — si le fichier est présent, il joue
à la place du son synthétisé. Aucune autre modification de code nécessaire.

Note : c'est à toi d'ajouter ce fichier (droits d'usage à ta charge),
je n'en fournis pas ici.
